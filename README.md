# Activity 3:  Finding the Hypotenuse of a Right Triangle

## Description
This is a program used to find the hypotenuse of a right triangle.

## How to run
To run this program, you need to first download and open this file. Afterwards, enter the two side values of the shorter sides of the triangle. Then run the program. 

## Input needed
Input the length of the shorter sides of the triangle 

## Sample output
Enter the length of side a: 6
Enter the length of side a: 8
The hypotenuse is: 10.00
